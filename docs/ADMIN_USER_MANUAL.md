# Mashambanzou Care Trust  
## Admin Panel User Manual  
### For Success Stories, Jobs, Tenders, Notices, Images & Website Text

**Admin website:** https://admin.mashambanzoucaretrust.com  
**Public website:** https://mashambanzoucaretrust.com

This manual is written for staff with little IT background. Follow the steps exactly in order. You do not need to write code.

---

## 1. Before you start

### 1.1 What the admin panel is

The admin panel is where you **add and update** content that appears on the public website:

| In admin you manage… | Visitors see it on… |
|---|---|
| Success stories | Success Stories page + homepage “latest stories” |
| Job openings | Careers page |
| Tender documents | Invitation to Tenders page |
| Notices | Noticeboard page |
| Website images | Photos/slideshows across many pages |
| Website text | Headings, paragraphs, button labels, menu names |
| Admin users | Who can log in to this panel |

### 1.2 What you need

- A computer with internet
- Google Chrome, Microsoft Edge, Firefox, or Safari (updated)
- Your **admin email** and **password** (ask the ICT lead if you don’t have them)
- Photos ready on your computer (JPG or PNG is best)
- For tenders: PDF (preferred), or Word DOC/DOCX

### 1.3 Important words

| Word | Meaning |
|---|---|
| **Published** | Visible to the public on the website |
| **Draft / not published** | Saved in admin only; public cannot see it |
| **Upload** | Taking a photo or file from your computer into the website |
| **Delete** | Permanently remove (usually cannot be undone) |
| **Edit** | Change something that already exists |

### 1.4 If the site shows “Coming Soon”

If the public site or admin shows a **Coming Soon** page, the live site has not yet been switched back on. Contact the ICT lead / hosting administrator. Normal admin work resumes when Coming Soon is turned off.

## 2. Sign in and sign out

### 2.1 Sign in (login) — step by step

1. Open your browser.
2. Go to: **https://admin.mashambanzoucaretrust.com/admin/login**
3. You will see:
   - **Email**
   - **Password**
4. Type your email carefully (example: `admin@mashambanzoucaretrust.com`).
5. Type your password.
6. Click **Sign in**.
7. If successful, you are taken to the **Success Stories** list.

**If login fails:**

- Check Caps Lock is off.
- Check email spelling and that there are no spaces.
- Try again carefully.
- If it still fails, ask an existing admin to recreate your account under **Admin Users**, or contact the ICT lead.

### 2.2 Sign out

1. Look at the top right of the page.
2. Click **Sign out**.
3. You return to the login screen.

**Tip:** Always sign out when finished, especially on shared computers.

### 2.3 Top menu (what each link is for)

After login, the top menu includes:

| Menu item | Purpose |
|---|---|
| **Success Stories** | Public-style list of stories (optional viewing) |
| **Stories Admin** | Add / edit / delete success stories |
| **Careers Admin** | Job openings |
| **Tenders Admin** | Tender documents |
| **Noticeboard Admin** | Notices and announcements |
| **Website Images** | Change site photos and slideshows |
| **Website Content** | Change site text and menu labels |
| **Admin Users** | Create new admin logins |
| **Sign out** | Leave the panel |

## 3. Success Stories Admin  
### End-to-end process: add, edit, publish, delete

**Where:** Top menu → **Stories Admin**  
**Address:** https://admin.mashambanzoucaretrust.com/admin/success-stories  
**Public page:** https://mashambanzoucaretrust.com/success-stories

### 3.1 What a success story is

A story with:

- A title
- A date
- A picture
- A short summary (optional)
- Full story text
- Published or draft status

Published stories (with a date of today or earlier) appear on the public website.

### 3.2 Add (post) a new success story

1. Click **Stories Admin**.
2. Click **Post a story**.
3. Fill in the form:

| Field | What to do |
|---|---|
| **Title** | Write a clear headline, e.g. “Community outreach reaches Nyabira families” |
| **Date** | Choose the story date. Use today’s date if it should appear immediately. A **future date** will hide the story until that day. |
| **Picture** | Click **Choose file** / **Browse**. Select a photo from your computer. **Required** when creating. Max about **5 MB**. Prefer JPG/PNG. |
| **Short summary** | Optional. 1–2 short sentences for the story card listing. Max about 500 characters. |
| **Story text** | Write the full story. Use Enter for new paragraphs. (Plain text — no fancy formatting toolbar.) |
| **Publish this story** | Tick this box if the public should see it. Leave unticked to save as draft. |

4. Click **Post story**.
5. You should see a success message, e.g. “Success story posted.”
6. Check the public page (refresh after a minute): https://mashambanzoucaretrust.com/success-stories

### 3.3 Edit a success story

1. Go to **Stories Admin**.
2. Find the story.
3. Click **Edit**.
4. Change any fields.
5. To replace the picture: choose a new file under **Picture**.
6. Click **Save changes**.

### 3.4 Unpublish (hide without deleting)

1. Edit the story.
2. Untick **Publish this story**.
3. Save.
4. It stays in admin as draft and disappears from the public site.

### 3.5 Delete a success story

1. On the stories list, click **Delete**.
2. Confirm when asked (“Delete this success story?”).
3. The story and its picture are removed. This cannot be undone easily.

### 3.6 Common mistakes

- Forgetting to tick **Publish this story** → story saved but not public.
- Using a **future date** → story waits until that date.
- Photo too large → upload fails; compress/resize the image and try again.

## 4. Careers Admin  
### End-to-end process for job openings

**Where:** Top menu → **Careers Admin**  
**Address:** https://admin.mashambanzoucaretrust.com/admin/careers  
**Public page:** https://mashambanzoucaretrust.com/careers

### 4.1 Add a job opening

1. Click **Careers Admin**.
2. Click **Post a job opening**.
3. Fill in:

| Field | What to do |
|---|---|
| **Job title** | e.g. “Programme Officer” |
| **Picture upload (optional)** | Optional photo for the job card. Max about **16 MB**. |
| **Application deadline** | Choose date **and** time when applications close. |
| **Publish on the website** | Tick to show on the public Careers page. |

4. Click **Post opening**.
5. Check https://mashambanzoucaretrust.com/careers

### 4.2 Edit / unpublish / delete

- **Edit:** Click **Edit** → change → **Save changes**.
- **Hide:** Untick **Publish on the website** → save.
- **Delete:** Click **Delete** → confirm.

### 4.3 How deadlines work

- Before the deadline: job shows as open (Apply/enquire available).
- After the deadline: listing can still show as **Closed**, but applications are treated as closed.
- To remove a job completely, delete it or unpublish it.

## 7. Website Images  
### End-to-end process for photos and slideshows

**Where:** Top menu → **Website Images**  
**Address:** https://admin.mashambanzoucaretrust.com/admin/website-media

This is where you change photos used around the public website (homepage hero, programme pages, board photos, management photos, galleries).

### 7.1 How sections work (simple explanation)

The page is divided into **sections**, each labelled clearly, for example:

- Homepage hero slideshow  
- Board member photos  
- Management photos  
- Programme page images and galleries  

Each card shows:

- What is currently showing on the website
- Whether it is a **built-in site image** or an **admin upload**
- Buttons like **Add image**, **Replace image**, **Edit**, **Delete**

### 7.2 Single image vs slideshow

| Type | How it behaves |
|---|---|
| **One image** (“Uses one active replacement image”) | Uploading a new image **replaces** the previous admin image. |
| **Slideshow / gallery** (“Supports multiple images”) | Uploading **adds** a new image to the set. Built-in images stay; your new images are added after them. |

### 7.3 Add an image to a section (recommended path)

1. Open **Website Images**.
2. Scroll to the section you want (e.g. **Homepage hero slideshow**).
3. Click **Add image** (or **Replace image** for single-image sections).
4. Fill in:

| Field | What to do |
|---|---|
| **Website section** | Confirm the correct section is selected |
| **Image label** | Short name, e.g. “Outreach clinic” |
| **Alt text** | Describe the photo for accessibility, e.g. “Health worker speaking with a community member” |
| **Sort order** | Number for slideshow order. **Lower numbers show first** (0, then 1, then 2…) |
| **Image** | Choose the photo from your computer. Max about **16 MB**. |
| **Use this image on the website** | Keep ticked so it is active |

5. Click **Save image**.
6. Return to the Website Images list and confirm the photo appears.
7. Open the related public page and refresh to confirm.

### 7.4 Edit an uploaded image

1. Find the uploaded image (badge: **Active**).
2. Click **Edit replacement**.
3. Change label, alt text, sort order, active status, or upload a replacement file.
4. Click **Save changes**.

### 7.5 Hide an image without deleting

1. Edit the image.
2. Untick **Use this image on the website**.
3. Save.
4. It moves to **Hidden admin uploads**.

### 7.6 Delete an uploaded image

1. Click **Delete**.
2. Confirm.
3. For single-image sections, the site returns to the built-in default photo.
4. For slideshows, that uploaded slide is removed; built-in slides remain.

### 7.7 Common website image sections

Examples you may see:

- Homepage hero slideshow  
- Homepage - Who we are image  
- Homepage impact cards (Clinical, Community, OVC, Human Rights)  
- Board & Governance hero slideshow and board member photos  
- Management photos  
- Clinical Healthcare, Community Strengthening, OVC Support, Human Rights page images and galleries  

### 7.8 Photo tips for non-technical staff

- Prefer clear, well-lit photos.
- JPG or PNG.
- Avoid very large camera files that fail upload — ask someone to compress if needed.
- Always fill **Alt text** so the site stays accessible.
- After uploading, always check the **public website**, not only the admin preview.

## 8. Website Content  
### End-to-end process for editing headings and text

**Where:** Top menu → **Website Content**  
**Address:** https://admin.mashambanzoucaretrust.com/admin/website-content

This is where you change words on the public site: titles, subtitles, paragraphs, button labels, and navigation names.

### 8.1 Opening a page to edit

1. Click **Website Content**.
2. You will see cards by page, e.g.:
   - Homepage  
   - Our Identity  
   - Navigation  
   - Careers  
   - Contact  
   - Donate  
   - and more  
3. Click the card for the page you want.
4. You see all editable fields for that page.

### 8.2 What the badges mean

| Badge | Meaning |
|---|---|
| **Default** | Still using the original website wording |
| **Custom** | You (or someone) have changed this text |

### 8.3 Field types

| Type | How you edit |
|---|---|
| Heading / subheading / CTA / navigation / stat | Single line of text |
| Paragraph | Larger box with formatting tools (bold, italic, link, lists) |

### 8.4 Change text and save — step by step

1. Open the page card (example: **Homepage**).
2. Find the field by its label (example: **Hero main heading**).
3. Click in the box and type the new wording carefully.
4. For paragraphs: use the toolbar if you need **Bold**, *Italic*, links, or bullet lists.
5. Scroll to the bottom.
6. Click **Save [Page name]** (example: **Save Homepage**).
7. Wait for the success message.
8. Open the public website page and refresh to confirm.

### 8.5 Reset one field to the original wording

1. If a field shows **Custom**, click **Reset to default**.
2. Confirm.
3. That field returns to the built-in wording.

### 8.6 Editing the navigation (menu labels)

1. Open **Website Content**.
2. Click **Navigation**.
3. Change labels carefully (example: “Contact us”, “Our Services”).
4. Save.
5. Check the top menu and footer on the public site.

**Caution:** Changing menu names does not change where the links go. Only change wording if you are sure. Prefer clear, short labels.

### 8.7 Important reminder

- Changing text here updates the live website (after refresh).
- Do not paste messy formatting from Word if you can avoid it — type cleanly or paste as plain text first if text looks broken.
- If you see raw tags like `<p>` on the site, edit that paragraph again in Website Content and re-save cleanly, or **Reset to default**.

## 9. Admin Users  
### End-to-end process for creating logins

**Where:** Top menu → **Admin Users**  
**Address:** https://admin.mashambanzoucaretrust.com/admin/users

Only trusted staff should do this.

### 9.1 Create a new admin user

1. Click **Admin Users**.
2. Click the create option (**Create** / create button as shown).
3. Fill in:

| Field | What to do |
|---|---|
| **Name** | Full name of the person |
| **Email** | Their work email (this becomes their login) |
| **Role** | Fixed as **admin** |
| **New password** | At least **8 characters**. Share privately with the person. |
| **Confirm password** | Type the same password again |

4. Click **Create admin**.
5. Give the person:
   - Admin URL: https://admin.mashambanzoucaretrust.com/admin/login  
   - Their email  
   - Their temporary password  
6. Ask them to sign in and keep the password private.

### 9.2 What this screen cannot do

The current panel lists and creates admins. There is **no simple edit/delete password reset screen** in the basic UI. For password resets or removing access, contact the system administrator / developer support.

### 9.3 Security tips for the team

- Do not share one password among many people if you can avoid it.
- Prefer one admin account per person.
- Sign out after use.
- Never post passwords in WhatsApp groups or email to many people.

## 11. Troubleshooting (for non-technical staff)

| Problem | What to try |
|---|---|
| Cannot log in | Check email/password; Caps Lock; ask another admin to create a new user, or contact ICT |
| I posted something but it is not on the website | Is **Publish** ticked? Is the date in the future? Refresh the public page. Wait 1–2 minutes and hard-refresh (Ctrl+F5 or Cmd+Shift+R). |
| Upload failed | File too big; compress photo/PDF; try JPG/PNG for photos; PDF for tenders |
| Photo looks cut off | Choose a photo that fits the space better; ask for help selecting landscape vs portrait |
| Wrong text on the website | Go to **Website Content** → correct page → edit → Save, or Reset to default |
| Menu wrong | Website Content → **Navigation** → fix label → Save |
| Admin shows Coming Soon | Ask ICT lead to turn off Laravel Coming Soon mode (`SITE_COMING_SOON=false`) |
| Public site shows Coming Soon | Ask ICT lead to turn off Next.js Coming Soon mode (`COMING_SOON=false`) |
| I deleted something by mistake | Contact support/developer; deletion may not be recoverable |

### File size limits (reminder)

| Area | Limit |
|---|---|
| Success Stories pictures | About **5 MB** |
| Careers / Notices / Website Images | About **16 MB** |
| Tender documents | About **20 MB** (PDF / DOC / DOCX) |
